
# HUBO Match Sync

Automatic synchronization of HUBO Handbal matches from Clubee.

## Structure

- download.js → downloads Clubee pages
- parse-clubee.js → generic Clubee parser
- liga.js → Liga runner
- heren1.js → Heren 1 runner
- dames1.js → Dames 1 runner
- j18.js → J18 runner
- merge.js → merges all competitions into activities.json
